## Design Notes
- Wanted simple interactions between user and interface
- Wanted to system to run itself, but allowing user to intervene before going back to automatic running
- Focused on simple interactions to reduce cognitive load
- Future Improvement: add ARIA labels to support screen readers and add labels to each sliders
